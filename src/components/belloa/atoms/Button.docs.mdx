  <div className="section-content">
    <p><strong>Use Button when you need to:</strong></p>
    <ul className="usage-list">
      <li>✓ Trigger an immediate action (submit form, open modal, confirm operation)</li>
      <li>✓ Navigate to another page or section (when styled as 'link' variant)</li>
      <li>✓ Perform a destructive action (delete, cancel, remove) with visual warning</li>
      <li>✓ Provide a secondary or tertiary action alongside a primary CTA</li>
      <li>✓ Create icon-only controls in toolbars or compact interfaces</li>
    </ul>
    
    <p style={{ marginTop: '1.5rem' }}><strong>Choose the right variant:</strong></p>
    <ul className="usage-list">
      <li><code>primary</code> → Main action, highest emphasis (deposits, bets, confirmations)</li>
      <li><code>secondary</code> → Supporting actions with moderate emphasis</li>
      <li><code>stroke</code> → Outline style for alternative actions</li>
      <li><code>ghost</code> → Low emphasis, minimal visual weight</li>
      <li><code>link</code> → Text-only, for inline navigation</li>
      <li><code>destructive</code> → Destructive actions (delete, cancel, remove)</li>
    </ul>
  </div>
</div>
